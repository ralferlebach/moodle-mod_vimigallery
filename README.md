# mod_vimigallery — ViMi Gallery

A read-only gallery of ViMi Pad knowledge maps for Moodle. Shows one or more maps
either embedded on the course page (like a label) or behind a link (like a page),
rendered through mod_vimipad's embeddable read-only editor.

Requires **mod_vimipad** (>= 0.9.4).

This is an early skeleton (0.1.0): uploaded JSON maps only. Album/swipe, activity
sources (mod_vimipad / qtype / datafield), curation, comments and comparison are
planned.
